# Entorno temporal de pruebas de Analytics

No fusionar esta rama con main. La web pública debe conservar VL_ANALYTICS_ENABLED=false. En Deploy Previews privados se usa true y una clave administrativa diferente de producción. Abrir la URL canónica deploy-preview-N--webvitalink.netlify.app, no el dominio público. Las funciones de prueba usan exclusivamente el almacén vitalink-analytics-test (getStore es compartido entre despliegues del mismo proyecto). No introducir datos médicos ni información real de pacientes. Verificar rechazo de cookies sin eventos, aceptación con POST 204, informe con clave de prueba, rechazo de clave incorrecta (401), y revocación. La función programada no se ejecuta automáticamente en Deploy Previews; eliminar manualmente el almacén de prueba cuando termine el ensayo. No publicar ni fusionar hasta revisar privacidad, consumo y resultados.
