# VitaLink Web Beta 10.0

## Cambios principales
- Se añadió un fondo decorativo fijo inspirado en VitaLink: ondas de pulso, cápsulas, órbitas y retícula sutil.
- El fondo se desvanece progresivamente al hacer scroll, para no competir con el contenido.
- Se añadió un ligero desplazamiento del fondo para reforzar la sensación de profundidad.
- El resto de la navegación y el carrusel de tres pasos se conserva intacto.
